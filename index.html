连接网易云账号

先在 Chrome 的网易云官网登录，再导入本机登录状态。

登录信息只在本机读取和保存，不会发给第三方解析服务。

第一次使用？安装本机登录助手
  1. 打开 Chrome 并访问 chrome://extensions/。
  2. 在 Chrome 扩展程序页面开启右上角的“开发者模式”。
  3. 点击“加载已解压的扩展程序”，选择 chrome-extension 文件夹：开发时位于项目根目录；打包后位于应用文件夹的 resources/app 下。如果已安装旧版助手，请先移除旧版。
  4. 回到拾音点击“从 Chrome 导入登录状态”，并在打开的 Chrome 页面确认。

助手仅读取当前 Chrome 中网易云网页的 MUSIC_U 和 __csrf，并直接传给本机播放器；不读取其他网站的 Cookie。

其他方式：扫码或手动导入

手动导入网页登录信息
  1. 切换到已登录的 music.163.com 网页，按 F12 打开开发者工具。
  2. 打开“应用”或“Application”，在左侧“存储 → Cookie”下选择 https://music.163.com。
  3. 找到 MUSIC_U，双击“值 / Value”，按 Ctrl+C 复制。
  4. 回到本窗口，在下面粘贴并点击“验证并导入”。

这是敏感登录信息，只粘贴到本机输入框，切勿发到聊天或截图。
